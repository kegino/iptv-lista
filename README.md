# IPTV Lista — As Melhores Listas M3U e Xtream Codes em 4K

Plataforma oficial do **IPTV Lista** (`iptvlista.site`), fornecendo listas M3U e credenciais Xtream Codes de alta estabilidade com mais de 35.000 canais ao vivo, filmes e séries para Smart TVs, celulares e TV Box.

## 🚀 Tecnologias

- **Framework**: TanStack Start + Vite + React 19
- **Estilização**: Tailwind CSS v4 + Radix UI + Lucide React
- **SEO & Otimização**: Schema.org estruturado (Product, FAQPage, HowTo, BlogPosting, OfferCatalog), OpenGraph completo, Canonical Tags dinâmicas, Sitemap XML e RSS Feed nativo.
- **Identidade Visual**: Backdrop cinematográfico *Avengers: Endgame* otimizado em WebP (~160 KB), paleta Cosmic Quantum Violet & Blue com botões Supernova Gold de alto contraste e legibilidade impecável.

## 💻 Executando localmente

```sh
git clone https://github.com/kegino/iptv-lista.git
cd iptv-lista
pnpm install
pnpm dev
```

## 📦 Build para Produção

```sh
pnpm build
```
